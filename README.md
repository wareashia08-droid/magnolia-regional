# Magnolia Regional Medical Center

A website for a fictional regional hospital in Georgia, designed and built by **Ashia Ware** for **CIST 2531 Web Graphics II** (October 2026).

The site is built around a magnolia brand with a plant-inspired color palette. It puts emergency guidance first and gives clear paths to care, specialists and doctors.

## Pages

- **Landing page** (`index.html`): emergency care, services, doctors, hours, campus map, billing, events, FAQ and an appointment request form
- **Specialty care** (`specialties.html`): eight specialties with what each covers and how to get started
- **Find a doctor** (`doctors.html`): nine sample doctors with search and an "Accepting new patients" filter
- **Sources and notes** (`sources.html`): brand and design choices, plus credits for every photo, font and library

## Built with

HTML, CSS, JavaScript, Tailwind CSS, Lucide icons and Google Fonts (DM Serif Display and Work Sans). The first version was made in Canva Code.

## Notes

Magnolia Regional Medical Center is not a real hospital. All names, doctors, addresses and phone numbers are sample content. Photos are from Pexels and Unsplash and are credited on the Sources and notes page. The appointment form saved through Canva in the original version, so on this site it shows an "unavailable" message.
